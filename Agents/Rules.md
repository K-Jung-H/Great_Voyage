# Rules

- 사용자 지시를 우선하고 기존 변경을 보존한다. 작업 전후 Git 상태를 확인한다.
- Unity 버전·장르·플랫폼은 확정 전 추정해서 설정하지 않는다.
- 씬, 프리팹, 에셋과 `.meta` GUID 및 참조 관계를 함께 보존한다. 임의 재생성 금지.
- Unity Editor 검증을 실행하지 못했다면 검증하지 않았다고 명시한다.
- Queue는 작업 목록이 아닌 최근 이벤트 FIFO다. 기본 N=100, config.json으로 변경한다.
- 대화와 도구 입력·출력은 접근 가능한 원문으로 기록한다. 요약은 원문처럼 표시하지 않는다.
- 내부 추론은 수집하지 않는다. 비밀·인증정보를 명령이나 프롬프트에 넣지 않는다. 이미 노출된 비밀은 Git에 올리기 전 제거하고 제거 사실을 기록한다.
- 중단은 실패나 무변경을 뜻하지 않는다. 실제 상태 확인과 근거 기록 후에만 resolve 또는 재실행한다.
- 동시 에이전트/다른 기기가 같은 기록 파일을 수정하지 않도록 작업을 순차 인계한다. 잠금 오류 시 강제 진행하지 않는다.
- 코드 변경 목적, 검증, 남은 작업을 State의 수동 영역에 기록한다. 자동 영역은 실행 상태만 나타내며 작업 성공을 판정하지 않는다.
- Git 동기화 전 diff와 기록 내용을 검토한다. 강제 push, 사용자 변경 삭제 금지.
