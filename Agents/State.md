## 저장 오류 수정 상태

사용자 Play의 오류창/런타임 읽기에서 `Invalid event identity or checkpoint`, sequence0/current=null을 확인했다. SaveCoordinator/사건 체크포인트를 기존 Newtonsoft의 공개 필드 전용·null 보존 직렬화로 통일했다. v9 읽기/v10 출력·슬롯·원자 저장/백업·손상 사건 거부는 유지한다. 예외를 Console에 남기고 게임 실행 오류와 저장 오류를 구분한다. **컴파일 오류/경고0이며 실제 재실행 해결 여부는 미확인**이다. 제안했던 메모리 회귀 검사는 실행하지 않았다.

## 이번 문서·Scene 정리

- RoadMap의 현행 11~13과 잔여 실행표로 중복 CompletionPlan을 통합했다. 확정 견인은 Architecture로 통합했다. 두 별도 문서는 전문을 History에 보존한 뒤 제거했고 링크를 갱신했다.
- State/Architecture의 누적 과거 현황도 History에 전문 보존 후 현재 역할별 내용으로 정리했다. GameDesign은 도입부 단계 대응만 수정하고 보존 원문·원본 기획/이미지는 유지한다. ReconstructionPlan·VerificationReport는 유효한 설계·검증 근거여서 유지한다.
- 계약 게시판을 갑판에서 선착장 함선 옆으로 이관했다. StarterShipWorld의 잘못된 원본 배치를 제거하고 Game의 Dock/Links에 행동/ID를 유지한 객체1개와 Geometry 표시를 둔다. 접안 함선·망원경 표시 크기, 망원경 Links 소유 및 ShipEditOverlay 해금 버튼 겹침을 수정했다.
- GameRoot는 Scene 소유, 기존 공간·캐릭터·화면 Prefab과 공통 상태/저장 ID를 유지한다. 게임 규칙·슬롯·패키지 변경 없음. 게시판의 중복 옛 표시2개도 제거했다. 최종 정적 검사 Game clean/stopped·939객체·누락 스크립트0·UI 참조967개/검사 오류0·편집 버튼5개 비겹침·게시판1개 선착장 소유 확인. 컴파일 up_to_date/failed=false/errors=[]/warnings=[]. 활성 문서 로컬 링크 오류0, GameDesign 보존 원문 HEAD와 동일. 기능 테스트·실제 저장·커밋/푸시/병합 없음.
